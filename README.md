## 💡 О проекте

**SkipIt** — клиент для подключения к VPN по подписке. Вставили ссылку от провайдера — и всё работает: серверы, флаги стран, трафик, срок подписки и правила, какие сайты идут мимо VPN.

Забудьте про настройку:
* 📋 **Ctrl+V — и готово** — ссылка на подписку или сервер вставляется в любом месте окна.
* 🧠 **Правила провайдера применяются сами** — российские сайты, банки и сервисы идут напрямую, остальное — через VPN. Ничего не нужно настраивать руками.
* 🌍 **Серверы с флагами и задержкой** — видно, где сервер и насколько он быстрый; самый быстрый выбирается одной кнопкой.
* 🎮 **Игры и программы — на ваш выбор** — можно пустить через VPN только нужные программы или, наоборот, исключить их.
* 🔔 **Живёт в трее** — закрыли окно, а VPN продолжает работать; подключиться и отключиться можно прямо из трея.
* 🔄 **Обновляется сам** — новая версия ставится одной кнопкой, без поиска установщика.

## 📥 Установка

1. Откройте [страницу релизов](https://github.com/FrI3nd7/skipit/releases) — самый верхний и есть самый новый.
2. Скачайте **`SkipIt-Setup-Windows-<версия>.exe`** и запустите его.
3. Скопируйте ссылку на подписку от вашего VPN-провайдера и нажмите **Ctrl+V** в окне SkipIt.
4. Нажмите на большую кнопку ▶▶ — готово.

Всё нужное уже внутри установщика — **больше ничего скачивать не надо**:

| Что внутри | Зачем |
| :--- | :--- |
| **SkipIt** | Сама программа: окно, трей, подписки, настройки |
| **Xray-core** | Подключение к серверам по протоколам VLESS, VMess, Trojan и др. |
| **sing-box** | Режим TUN: весь трафик компьютера и правила по программам |

## 🔌 Режимы подключения

| Режим | Что идёт через VPN | Когда выбирать |
| :--- | :--- | :--- |
| **Смешанный** *(по умолчанию)* | Браузеры — через прокси, остальные программы — через TUN | Лучший вариант для большинства: всё работает, сайты определяются точнее |
| **TUN** | Весь трафик компьютера | Игры и программы, которые не умеют работать через прокси |
| **Прокси** | Только программы, использующие системный прокси (браузеры) | Когда нельзя дать права администратора |
| **Только порты** | Ничего в системе не меняется — локальные SOCKS и HTTP | Для ручной настройки отдельных программ |

## 🧭 Маршрутизация

| Что | Как работает |
| :--- | :--- |
| **Правила провайдера** | Если провайдер отдаёт полный конфиг (JSON), SkipIt использует его целиком: какие сайты напрямую, какие через VPN, что блокируется. Краткое содержание правил видно в разделе «Маршрутизация» |
| **Свои профили** | Можно создать свои правила или взять шаблон («Россия напрямую», «Только заблокированное»). Профилями можно делиться ссылкой, понимаются и ссылки из Happ |
| **Приложения** | Два режима: «все через VPN, кроме списка» или «только выбранные через VPN». Программу можно выбрать из запущенных, по файлу, папке или имени |

## 🔄 Обновления

SkipIt сам проверяет обновления при запуске. Если есть новая версия, внизу меню появится пометка **«Обновление»** — одна кнопка скачает и установит её.

| Канал | Что приходит |
| :--- | :--- |
| **Стабильный** *(по умолчанию)* | Только стабильные релизы. Пока SkipIt в альфе и стабильных версий нет — приходят альфа-версии |
| **Бета** | Всегда самые свежие версии, включая тестовые — новые функции раньше, но возможны ошибки |

Канал меняется в **Настройки → О приложении**. Ядра Xray-core и sing-box обновляются там же.

## ❓ Частые вопросы

**Нужно ли что-то докачивать после установки?**  
Нет. Всё уже внутри установщика.

**Где SkipIt хранит подписки?**  
В папке `%APPDATA%\SkipIt` — её можно открыть из Настроек. При обновлении и переустановке подписки сохраняются.

**VPN работает, а окна нет.**  
SkipIt свёрнут в трей — нажмите на его значок рядом с часами. Полностью выйти можно через меню значка → «Выход».

**Одновременно открыт другой VPN-клиент.**  
Два VPN сразу мешают друг другу. Отключите второй клиент перед подключением SkipIt.

---

## 🗑️ Удаление

**Параметры → Приложения → SkipIt → Удалить.** Перед удалением SkipIt сам корректно отключит VPN и вернёт настройки прокси — интернет не пропадёт. Папка с подписками `%APPDATA%\SkipIt` остаётся на случай переустановки; её можно удалить вручную.
